FastAPI is a modern, high-performance web framework for building APIs with Python 3.7+.
It was created by Sebastián Ramírez and first released in 2018. FastAPI is built on top
of Starlette for the web parts and Pydantic for data validation. It is one of the fastest
Python frameworks available, comparable to NodeJS and Go in benchmarks. FastAPI
automatically generates interactive API documentation using Swagger UI (at /docs) and
ReDoc (at /redoc). It uses Python type hints for request/response validation and
serialization. Async support is built-in via async def route handlers and the ASGI
interface. Dependency injection is a first-class feature, making it easy to share logic
across endpoints. FastAPI supports OAuth2, JWT tokens, and other authentication schemes
out of the box. It is widely used in production systems at companies like Microsoft,
Uber, and Netflix.
